# pbfdoc: свод счетов Bolt по неделям

Веб-платформа для бухгалтерии L.K.W. - Lines SIA. На страницу бросают выгрузку Bolt «Klientu rēķini» (CSV) и/или PDF-счета поездок, сколько угодно файлов за раз. Страница сразу показывает свод по неделям и отдаёт Excel в формате шаблона `BOLT_xx_week_kopsavilkums`.

Все файлы обрабатываются в браузере пользователя. На сервер ничего не загружается, поэтому нет ни лимита на число файлов, ни базы данных.

## Что получается в Excel

- **Kopsavilkums:** итоги по неделям и за месяц, сверка с суммами CSV.
- **`NN_week`:** лист на каждую неделю (пн–вс) в колонках шаблона: Nr.p.k., Darījuma datums, Dokumenta Nr. no sistēmas, Darījuma vieta, Darījuma kopsumma, Maksājuma veids, Avots, Summa bez PVN, PVN 21%, Dzēram-nauda, Bolt konts, Neapl. D., Atgrieš., Kopā, Komisija. Справа: время поездки, получатель, его рег. номер и номер НДС.
- **Visi rēķini:** все поля Bolt по каждому счёту, с фильтрами.
- **Pārbaudīt:** что нужно проверить вручную (нераспознанные строки PDF, пропуски в нумерации счетов).

Правила расчёта:
- Если НДС не равен 21% от всей суммы, разница считается необлагаемой частью (аэропортовый сбор около 2 €) и попадает в «Neapl. D.».
- Комиссия = (сумма без НДС + НДС) × 25% × 1,21. Процент можно поменять на странице. Сверять с EDS.
- Чаевые, Bolt konts и возвраты берутся из PDF. Если PDF нет, эти колонки заполняются вручную (в Excel они жёлтые).
- Если по счёту есть только PDF, без CSV, строка собирается из PDF (источник «PDF»).

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # проверки разбора CSV/PDF и сборки Excel
npm run build      # статический сайт в dist/
```

### Консольная версия

Тот же результат без браузера:

```bash
npm run cli -- ./faili --out ./rezultats
npm run cli -- aprilis.csv r1.pdf r2.pdf --rate 25
```

## Публикация на Vercel

1. На vercel.com: **Add New → Project** → выбрать репозиторий `pbfdoc`.
2. Vercel сам определит Vite (Build: `npm run build`, Output: `dist`). Нажать **Deploy**.
3. Полученную ссылку отправить коллегам. Каждый push в `main` обновляет сайт автоматически.

Бесплатный тариф Vercel (Hobby) по правилам только для некоммерческого использования. Для фирмы нужен Pro. Бесплатная альтернатива с разрешённым коммерческим использованием: Cloudflare Pages (те же настройки: `npm run build`, папка `dist`).

## Структура

```
index.html             разметка страницы
src/main.js            интерфейс: загрузка файлов, таблицы, скачивание
src/style.css          стили (светлая и тёмная тема)
src/lib/csv.js         разбор CSV Bolt (UTF-8 и пересохранённого Excel'ем ANSI/TSV)
src/lib/pdf.js         разбор PDF-счёта поездки
src/lib/summary.js     месяцы, недели, суммы, номера недель
src/lib/excel.js       сборка Excel по шаблону
src/lib/workspace.js   набор загруженных файлов
cli/                   консольная версия
test/                  тесты на выдуманных данных
```

Реальные CSV, PDF и XLSX в репозиторий не попадают (см. `.gitignore`): в них имена клиентов.
